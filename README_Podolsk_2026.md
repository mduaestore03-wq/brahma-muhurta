# Брахма-мухурта — Подольск, Московская область, 2026

**Период:** 22.10.2026–31.12.2026 (71 гражданская дата).
**Координаты:** 55.42419°N, 37.55472°E; высота 162 м.
**Часовая зона:** `Europe/Moscow` (UTC+03:00), без перехода на летнее время.
**Восход:** NOAA-совместимая apparent-конвенция (верхний край диска, стандартная рефракция 0.833°), чтобы сравнение с внешними астрономическими сайтами использовало одинаковую физическую границу.

## Содержимое

- `Brahma_Podolsk_2026_Explanations.md` — подробные пояснения каждого дня, титхи, накшатра, йога, карана, смены внутри окна, акцент и упражнения.
- `Brahma_Podolsk_2026_Practices.md` — компактные рекомендации на каждую дату.
- `Brahma_Podolsk_2026_Calendar.csv` — данные в CSV (UTF-8 BOM), включая оба метода времени и традиционную символику.
- `brahma_muhurta_2026.py` — модуль восхода и заката.
- `brahma_muhurta_daily_explanations_2026.py` — генератор обоих Markdown и CSV.

## Запуск на Windows

```powershell
py -m pip install pyswisseph tzdata
py brahma_muhurta_daily_explanations_2026.py --start 2026-10-22 --end 2026-12-31 --latitude 55.42419 --longitude 37.55472 --elevation 162 --timezone Europe/Moscow --place "Подольск, Московская область, Россия" --sunrise hindu --output-prefix Brahma_Podolsk_2026_Explanations
```

При запуске `*_practice.md` создаётся как `Brahma_Podolsk_2026_Explanations_practice.md`; готовый архив переименовывает его в `Brahma_Podolsk_2026_Practices.md` для удобства.

## Окончательная методика приложения

Приложение использует единое фиксированное окно: начало за 96 минут до местного восхода, конец за 48 минут до него. Это определение приведено в [OUM.RU](https://www.oum.ru/yoga/vedicheskaya-kultura/brakhma-mukhurta/). Метод `window_night15` сохранён только в исходном снимке аудита и не используется приложением.

Восход `hindu`: геометрический центр Солнца на уровне горизонта, без атмосферной рефракции и с геоцентрической конвенцией. **Это не время первого видимого края диска.**

Не путать ночь от захода до восхода с астрономической темнотой: вторая определяется по солнечной высоте -18°.

## Методологическая граница

Положение Солнца/Луны, времена и принадлежность расчётной точки титхи/накшатре/йоге/каране — астрономически вычисляемые свойства. Их религиозное значение принадлежит традиции, но астрономия **не подтверждает** причинного влияния сочетаний на здоровье, психику и результаты тайцзи. Практические акценты — педагогические подсказки, а не персональные предсказания.
